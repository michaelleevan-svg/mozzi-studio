개인정보처리방침 (Privacy Policy)

시행일: 2026년 10월 26일

1. 사용하는 정보

Mozzi Studio는 채널 운영자 본인이 Google 계정으로 승인한 범위 안에서 YouTube Data API와 YouTube Analytics API를 사용합니다. 사용 목적은 본인 채널의 동영상 업로드, 라이브 방송 생성·관리, 재생목록·채널 정보 수정, 댓글 답글, 조회수·시청 통계 확인입니다.

2. 저장과 공유

인증 토큰과 통계는 운영자 본인의 컴퓨터에만 저장되며, 제3자에게 판매하거나 공유하지 않습니다. 다른 사용자의 개인정보는 수집하지 않습니다. 공개 댓글은 답글을 달기 위해 읽을 뿐 별도로 보관·분석해 외부에 제공하지 않습니다.

3. 권한 철회

Google 계정의 보안 › 타사 앱 액세스에서 언제든 권한을 철회할 수 있습니다.

4. Google API 서비스 사용자 데이터 정책

Mozzi Studio의 Google API에서 받은 정보 사용은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. YouTube API 서비스를 사용하며, YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

5. 문의

이 앱의 Google 동의 화면에 표시된 지원 이메일로 문의해 주세요.

Mozzi Studio uses YouTube API Services only for the channel owner's own channel, stores tokens and statistics locally on the owner's computer, and does not sell or share any data. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.
